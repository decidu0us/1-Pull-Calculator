# 抽卡计算器专用仓库
##     输入内容：
    需要输入内容为：a，b，c，d，e，f，g
    a=已抽多少抽
    b=剩余天数（备注 今天每日已完成，凌晨4点后更新日期）
    c=活动获得原石数
    d=拥有原石数
    e=拥有星辉（原神界面显示星辉，崩铁界面显示星芒）
    f=拥有限定抽
    g=拥有常驻抽
    
    
##     原神计算公式：
    每跨x月，f的数值+5x，g的数值+5x，d+1600x(备注：新老深渊更新)
    每跨y版本，g的数值+5y0（纪行），f的数值+4y2（大月卡），d的数值+300y1+680y2+600y4+450y5（前瞻y1=300 +大月卡y2=680  + 更新y4=600 + 危战y5=450），
    剩余天数b=（今天至卡池开始日期+21）-1（公式不可将括号去除直接列为：今天至卡池开始日期+20）
    卡池结束剩余原石数h=b*（60+y3）+c+d
    第一次基础抽数i=h/160（向下取整）+（e+g/5）/5（向下取整）+f
    第二次基础抽数j=i/25（向下取整）
    可抽数k=i+j
    总抽数l=k+a
    
    
##     崩铁计算公式：
    每跨x月，f的数值+5x，g的数值+5x，
    每跨y版本，g的数值+5y0（纪行），f的数值+4y2（大月卡），d的数值+300y1+680y2+600y4（前瞻y1=300 +大月卡y2=680  + 更新y4=600），
    每跨1周，g+1，d+225（币战/宇宙更新）
    每跨2周，d+900(备注：深渊更新)
    剩余天数b=（今天至卡池开始日期+21）-1（公式不可将括号去除直接列为：今天至卡池开始日期+20）
    卡池结束剩余原石数h=b*（60+y3）+c+d
    第一次基础抽数i=h/160（向下取整）+（e+g/1.25）/20（向下取整）+f
    第二次基础抽数j=i/25（向下取整）
    可抽数k=i+j
    总抽数l=k+a
    

## 显示内容：
    跨月x，跨版本y（界面要求：这两个数在同一行）
    卡池结束时剩余原石数h（h显示为具体数值）
    可抽数k（k显示为具体数值）
    总抽数l（l显示为具体数值）
    

## 功能要求：
###     1、计算器
    c栏加入计算器功能，不用输入具体数值，可以输入算数式，比如多少加多少，c后台计算数值
###     2、日历
    b栏加入日历功能，可标记两个日期：1、自动标记今天（直接从日历获取当日日期）；2、卡池开始日期
    （卡池开始日期可以在今天之前）
    设置按钮备注是此卡池是上半还是下半。
    若设置为下半，上半卡池时间为下半卡池前21天。
###     3、时钟
    b栏加入时钟，跨日时间延长4小时，即凌晨四点后后再更新当天日期，（例子：8月4日凌晨3点仍然计算为8月3日）
###     4、跨月跨版本跨周计算
    自动计算是否跨月，跨月计算是，卡池最后一天是否跨月，跨月显示x值，不跨月显示x=0。
    自动计算跨版本，跨版本显示y值，不跨版本显示y=0，每个版本为42天，以上半卡池开始时间为版本更新时间。计算今日至上半卡池开始时间，若大于-42且小于等于0，y=0；大于0且小于等于42，y=1；逢42的正倍数y+1。
    崩铁自动计算跨周，不论当天星期几，到下个周一记为1，至下下个周一记为2，以此类推，2026年8月3日记为第0周，与至相隔为偶数周，d+900。
    相隔距离为正表示还有多少天到版本更新时间/上半卡池更新时间。
###     5、个性化按钮
    y0纪行拿满按钮，y1前瞻按钮，y2大月卡按钮，y3小月卡按钮
    y0有按钮可开启或关闭。默认开启。开启时y0=y-1，关闭时y0=y。
    y1有按钮可开启或关闭。离上半卡池开始日期<12天默认关闭，离上半卡池开始日期<或=12天默认关闭。关闭时y1=y-1，开启时y1=y。
    y2有按钮可开启或关闭，默认关闭，备注为大月卡。关闭时y2=0，开启时y2=y-1(默认此版本已拿全奖励)。
    y3有按钮可开启或关闭，默认开启，备注为小月卡，开启时y3=90，关闭时y3=0。
    值y4=y5=y
    在界面加一个按钮，点后可显示公式，也可对公式进行更改。
###     6、自定义背景
    分为基础版和固定背景版。
    默认背景均为 申鹤.jpg
    基础版可对网页端背景进行更改，可上传图片自定义背景，图片自动拉伸适应，有记忆功能，可以对更换背景后文件进行下载保存。
    固定背景版在网页端，隐藏自定义上传背景功能。其它与自定义版一样。
    双版本手机端背景统一为默认背景，不可编辑。
###     7、背景编辑
    显示两个透明度选项，蒙版按钮和恢复按钮。
    默认界面透明度拉到最高，在最右侧（能看到背景图片），图片透明度拉到最低，在最左侧（完全不透明）。
    增加界面蒙版按钮，默认关闭，开启背景图片被遮住部分变模糊。关闭背景被界面遮住部分变清晰。
    对两个透明度栏目，界面蒙版按钮保留记忆功能
###     8、版本切换
    原神/崩铁切换，按下后可以在原神和崩铁两个模式之间切换。
